Notes while we massage this
Tiles ask questions, they don't name metrics. "Is it safe to put in front of clients?" rather than "Safety". Same four dimensions underneath, so a builder learns the mapping for free and an owner never meets the vocabulary.
Missing data says so. Untested versions are gaps in the bars, never interpolated; "Not measured" beats a zero. The Comparable only / Full history toggle is my answer to the discontinuity problem — strict honesty by default, the messy truth on request.
Every day-one gap resolves to one action. Quality, trends and baseline all unlock with "run the set", so a new user has exactly one thing to do rather than three competing nudges.
Open before merging into v4: this page has no Build/Test toggle — you arrive from the agent list and leave via Open in builder. That keeps the two-mode toggle we just built intact, but it means Overview is a destination, not a third mode. Worth confirming that's the model before I wire it in.
