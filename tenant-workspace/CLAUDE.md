# Project notes

Prototype: "Platform" Data & AI catalog + Studio (Landing Page.dc.html).

- Tenancy model: the use-case dropdown in the top panel IS the tenant. "CDAO - General Purpose" is every user's default tenant — all journeys start there.
- Personas: Member (default), Contributor, Owner — switched via the persona pill in the top-right of the top panel.
- Journeys will be split by persona × use case; the LHS nav (currently the General Purpose set) will vary per tenant.
- Top panel (hamburger, Platform wordmark, use-case dropdown, persona switcher) stays constant across ALL views.
